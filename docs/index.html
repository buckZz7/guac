Sponsored offers lower
your per-token cost.

guac sits between your agent and its model. You opt into a few sponsored offers a day. That advertiser money — plus cheap, quality-gated supply — cuts what you pay for inference. The sponsorship is a simple "brought to you by" message you see on the response; the model is never touched. No credits, no wallets. The price is just lower.

Open the portal How it works
advertiser ──$──▶ guac ──$──▶ suppliers (SN64 / SN53 / SN28 / retail) guac ──◀─ you pay a discounted rate ── user_saving = (retail − wholesale) + (ad money − guac fee) · split always public

How the money flows

🎯

You opt in

Pick how many sponsored offers a day to see (1 / 5 / 10). More offers, bigger discount. Sign up in the portal, get an API key + base URL.

💬

"Brought to you by"

The sponsorship rides on the response for you to see — it's never fed into the model, so it costs no tokens and never influences inference.

🧾

Transparent split

The discount is a lower price, never a credit. User saving = sponsor money minus guac's fee. Always public, always reconcilable.

For advertisers — a real ad manager

🖥️

Self-serve console

Sign in with a magic link, create offers, set a budget, pause or resume anytime. No sales call, no master key.

📊

Per-impression billing

You're billed per delivered impression. See spend, impressions, and budget remaining in real time. An offer auto-pauses when its budget is spent.

✅

Honest clicks

Clicks are logged only when the agent actually acts on your offer — an attribution callback. Proof the offer mattered, not that it was shown.

Cheap supply, gated on quality

⚡

Quality first

Never "cheapest miner wins." Each source is scored deterministically on latency + success. Degraded suppliers recover after a cooldown.

🔁

Failover

Requests route across the pool. One miner's bad day is never your bad day.

📈

Real stats

Impressions are metered per request. Clicks are honest — logged when the agent actually acts on an offer via an attribution callback.

Run it — it's live

guac runs as a hosted service. Sign up at the portal to get an API key + base URL, then point any OpenAI-compatible agent at it.

# gateway is OpenAI-compatible. Point any agent at the hosted service.
$ # 1. get a key at https://addguac.fly.dev/portal
$ hermes config set model.provider custom
$ hermes config set model.base_url https://addguac.fly.dev/v1
$ hermes config set model.api_key guac_<your-key>

# or self-host from source
$ .venv/bin/python gateway.py --port 8000
