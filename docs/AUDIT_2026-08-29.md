# guac audit — 2026-08-29

Scope: full read of gateway.py, portal.py, portal_html.py, payments.py,
settlement.py, suppliers.py, oauth.py, limits.py, config.py, mailer.py,
Dockerfile, docs/, plus live probes of addguac.fly.dev (healthz, portal
login flow, Fly env/secrets/volumes) and a full local test run (15 suites,
all passing). Every finding below was verified, not inferred.

Goal being audited against: a simple product where users save money on
frontier models, and advertisers reach users inside their agents.

---

## P0 — these block the product

### 1. The portal is dead in production
Prod has `ADGATE_DEV_MODE=0`, no OAuth secrets, no SMTP. Confirmed by
probing: POST /portal/user/login returns "Email delivery isn't configured
yet — sign-in links can't be sent." Meanwhile the landing page's primary
CTA is "Get started free" → /portal → dead end. Every visitor who clicks
the main button hits a wall.
Fix options (in order of effort):
  a. Set the two GitHub OAuth secrets (one-time, ~20 min) — the whole
     OAuth path is already built and tested, it's just unconfigured.
  b. Until then, make the landing CTA point at the API signup that DOES
     work (`POST /signup`) with a copy-paste curl, and say "portal
     sign-in coming soon" honestly.

### 2. Fake inventory is live
No portal offers exist in prod, so `_active_offers()` falls back to
ads.json: Tesla, Wendy's, NordVPN, Notion, Oura, TurboTax, Headspace —
none of whom are advertisers. Real users get "Sponsor: NordVPN — 66% off"
footers, and /go/<id> clickthroughs route to those brands' sites with
`utm_source=guac`. This directly contradicts the "honest inventory, no
fabricated reach" positioning, and impersonating brand offers (some with
invented claim codes) is a legal exposure, not just a credibility one.
Fix: ship with ZERO ads until a funded offer exists — the system already
degrades gracefully to no-ads. Delete ads.json from the prod image or
gate the fallback behind an explicit `ADGATE_ALLOW_DEMO_ADS=1`.

### 3. "Pay less for AI" has no referent
There is no user billing anywhere in the codebase. Users pay nothing, so
"pay less" / "discount rate" / settlement's `user_paid` are all
counterfactual math. Worse, the user dashboard computes "estimated
savings" as `savings += 0.20` per sponsored request — a rate added as if
it were dollars. The product is actually "free inference subsidized by
sponsors," which is a STRONGER, simpler pitch than "pay less."
Decision point: free-with-ads (recommended — simpler, no billing infra,
matches "save money" literally: you save 100%) or paid-with-discount
(requires user billing before the claim is true). Rewrite all copy once
chosen; delete the fake savings number either way.

### 4. Auth holes in the advertiser portal forms
`POST /portal/advertiser/offer` authenticates purely by a form `email`
field: anyone who knows a registered advertiser's email can create offers
on their account. Same for `.../offer/{id}/toggle` — anyone can pause a
live advertiser's offers. (The topup form correctly requires the token.)
Fix: require the session cookie or advertiser token on both routes.

### 5. Sponsor links are unclickable where they're actually seen
`_footer_text` emits `[Learn more](/go/<offer_id>)` — a RELATIVE link.
The delivery surface is a terminal or Telegram; a relative path is dead
there. The entire click funnel depends on this link. Fix: prefix with
`PUBLIC_HOST`. (Verified in code; this breaks /go attribution in prod.)

## P1 — product & economics

6. **Frontier-model gap.** The stated goal is savings on frontier models,
   but the pool pins GLM-5.2 (chutes/engy) and deepseek/free models
   (OpenRouter). Prod secrets only include OPENROUTER_API_KEY, so today
   all real traffic routes to OpenRouter free models at $0 cost. Two
   honest options: (a) pass-through model routing — when the client asks
   for a real slug (gpt-5, claude-...), forward it to OpenRouter
   unmodified, which makes guac a genuine "any model, ad-subsidized"
   gateway; (b) reposition copy to "top open models at near-zero cost."
   Don't say frontier while serving only open-weight.
7. **Advertiser tokens are inference keys.** `verify_gateway_key` accepts
   advertiser tokens, so `adv_...` grants free inference as
   "advertiser:<email>". Split the namespaces.
8. **No token cap.** `ADGATE_DAILY_TOKEN_CAP` unset = unlimited. A leaked
   user key burns unbounded upstream spend. Set a cap.
9. **Settlement period is mislabeled.** `settle()` reads ALL ledger rows
   and ALL payments debits ever, but labels the statement with today's
   date. Either filter by period or label it "lifetime."
10. **`intents` is dead weight.** The demand-gated pivot removed topic
    matching, but offers still collect/validate/store intents and the
    advertiser form asks for them. Remove or it reads as a feature that
    doesn't exist.
11. **Session TTL is 1h.** Combined with the broken login, re-auth is
    painful. Raise to ~30 days once auth works.

## P2 — website design & copy

12. **Hero rewrite.** Current: "Pay less for AI. Advertisers cover part
    of the cost." Suggested (free-with-ads): "Your agent, sponsored.
    Route any OpenAI-compatible agent through guac and pay nothing —
    a disclosed sponsor below a few answers a day covers the bill. The
    model output is never touched." Lead with the one-URL setup, since
    that IS the product.
13. **Show the meter.** guac's moat is honest metering — requests served,
    impressions delivered, dollars passed through — all already in the
    ledger. A live public counter on the landing page turns the trust
    claim into a receipt. No other ad platform can show this.
14. **Missing sections:** pricing (even if "$0 — sponsor-funded", say it
    plainly), which models are served (transparency), an agents/setup
    doc page. FAQ dodges pricing entirely.
15. **Design:** emoji card icons (💰🔒🕵️🎯) — swap for SVG or drop.
    Operator /dashboard is dark-themed while everything else is light —
    unify. Add og:image; og:url is hardcoded. The favicon is a text "g"
    in SVG — fine for now, but it's the whole brand mark.
16. **The NordVPN mock** in "What it looks like" uses fake inventory —
    replace with a generic "Sponsor" example or a real partner once one
    exists.
17. **Name:** addguac.fly.dev is fine and memorable; get a real domain
    before advertiser outreach (ads-in-AI advertisers will judge).

## P3 — engineering notes (all minor at v1 scale)

18. `balance_for()` re-reads the whole payments ledger per impression —
    fine now, cache per-process later.
19. `/backup` returns user API keys + advertiser tokens over HTTP
    (master-key-only; acceptable, just be aware).
20. No CSRF tokens on portal forms — moot until #4's auth is fixed.
21. 15/15 test suites pass locally; the agnostic invariant test is a
    real asset — keep it in CI.

## What's genuinely good (don't touch)

- The core invariant (footer below `---`, model content byte-identical,
  finish_reason gate) is clean, tested, and is the actual product.
- Demand-gated cadence: no funded offer → no ads. That's the honest
  engine; everything else should hang off it.
- Supplier quality gate with failover + recovery cooldown is solid and
  deterministic.
- Flat-JSON-on-volume state is the right scale choice for v1.
- The payments ledger as source of truth (balance = sum of deltas) is
  exactly the kind of design that survives an audit.

## Suggested order of attack

1. Fix #5 (absolute /go links) + #4 (form auth) — small diffs, real bugs.
2. Kill fake inventory (#2); serve zero ads until funded.
3. Decide free-with-ads vs paid; rewrite copy (#3, #12-14).
4. GitHub OAuth secrets (#1) so the portal works.
5. Pass-through model routing (#6) so "frontier" is true.
6. Live meter on the landing page (#13) — the differentiator.
